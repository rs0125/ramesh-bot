## Remaining limits

The semantic verifier can reject an otherwise useful answer or ask for an unnecessary repair. Long CRM lists can still lose native dates during formatting, and concise owner questions can omit a relevant operational check. An occasional stock phrase can survive model formatting. These remain measured quality gaps, not completed guarantees. Whole-answer source revalidation, per-operation MCP connections and several model passes add latency; account-wide serial processing can delay other chats. The harness uses the same provider/model family as its judge and needs human review of ambiguous failures. None of these tests establishes parity with Claude.

At this v7 baseline, reminder scheduling, writes, media extraction, calendar/HRMS tools and a dedicated planning agent were separate increments. Media and the role split are implemented in the later record linked above. The assistant can plan and draft around user-provided information but must not claim these actions have happened.
