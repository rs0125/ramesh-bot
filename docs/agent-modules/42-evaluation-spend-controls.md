# 42. Evaluation spending controls

The operator reported excessive evaluation spend and requested Luna for low-level
model checks, with explicit approval before any Sol tests. Stop the in-flight paid
run and preserve its completed rows as partial evidence. Do not rerun it to obtain
a green summary. Production inference is separate from testing configuration.

Routine text-agent and grader checks default to `gpt-6-luna`, independently of the
production `OPENAI_MODEL`. Start with one trial and one concurrent case. A shared
preflight rejects runs exceeding a default three-trial allowance unless a larger
`--max-trials` is explicitly provided. This bounds scenario executions, not dollars
or HTTP requests; retries and multiple graph stages still consume tokens.

Any Sol model in the agent, grader, comparison profiles or private playground
requires an explicit `--sol-approval <reference>` before paid calls. The reference
records the user's approval for the stated scope; it is not itself permission and
must never be generated by the assistant without asking the user. Before asking,
state models, cases, repetitions and estimated spend/limits. Historical authorization
to test does not override this new requirement. Ordinary source/status reads and
deterministic tests do not need model approval.

Paid CI becomes manual only, with explicit case IDs, model and trial allowance.
Remove automatic weekly paid execution and automatic full grader calibration.
Default both agent and grader to Luna; allow Sol only with the approval field.
Do not change production or the interactive playground's model as part of this
testing policy. STT needs an audio-capable model; its dedicated paid benchmark is
also bounded, not silently changed to a text model.

Validate these controls offline: model selection independent of production env,
agent/grader/private-server Sol detection, bounded trial counts, and rejection
before network work. No model calls are required to test the policy. Luna results
are inexpensive screening feedback, not proof of Sol production behavior or a
replacement for human review of consequential outcomes.

Model identifier and Responses compatibility: [official GPT-6 Luna documentation](https://developers.openai.com/api/docs/models/gpt-6-luna).
