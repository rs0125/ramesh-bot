# Transcription model comparison

Spec recorded 2 October 2026, before the comparison runner. This supplements the [voice delivery contract](35-voice-transcripts.md).

## Decision

Compare completed WhatsApp audio transcription, not live-call turn detection. Reuse the authorized logistics-bot OpenAI key. Probe the documented `gpt-transcribe`, the existing `gpt-4o-transcribe`, and `gpt-4o-mini-transcribe` using the actual bounded media processor. A model name being documented does not establish that the current project has access; retain access failures instead of silently substituting a model.

Current official list prices: OpenAI GPT-Transcribe $0.0045/min; GPT-4o Transcribe estimated $0.006/min; GPT-4o Mini Transcribe estimated $0.003/min. Other candidates: ElevenLabs Scribe v2 $0.22/hour before add-ons; Deepgram Nova-3 Multilingual prerecorded pay-as-you-go $0.0052/min. Provider quality claims are not independent evidence that one wins on WareOnGo messages. Sources: [OpenAI pricing](https://developers.openai.com/api/docs/pricing), [GPT-Transcribe](https://developers.openai.com/api/docs/models/gpt-transcribe), [Scribe API pricing](https://elevenlabs.io/pricing/api), [Deepgram pricing](https://deepgram.com/pricing).

## Repeatable local harness

Use fictional scripts generated with local espeak-ng and encoded to mono Ogg/Opus by ffmpeg. Include English logistics, numbers and corrections, a Hindi negation, and English/Hindi segments in one message. Preserve references, audio hashes, model name, elapsed processing time, raw transcript and explicit semantic checks. Judge critical names/numbers/negation and requested content, not punctuation or whether Hindi is transliterated. Run each model twice per sample and retain every trial. This is a compatibility and regression smoke test, not a human-audio word-error-rate benchmark.

Only the STT API receives the generated bytes. No business data, real voices, Supabase records or WhatsApp transport are involved. Store artifacts under ignored `.local/stt-evals`; do not log credentials or provider error bodies. API failures record status/classification only. Expose a paid opt-in command; ordinary CI continues to use mocked provider tests. Keep the existing provider/model configuration until access and the comparison justify a local change.

## Interpretation

Report measured synthetic outcomes and latency separately from vendor claims. A narrow pass cannot prove accuracy on accents, real Hinglish code-switching, loud background noise, long audio or unusual business names. A future private corpus should contain consented representative recordings with human-checked references and protected outcome labels. Do not copy real customer names or voice recordings into public test fixtures.
